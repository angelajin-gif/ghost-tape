# Project structure

```
/
├── .kiro/                 # specs, steering, hooks — never gitignored
├── src/
│   ├── modem/             # pure TS library: bytes <-> samples (no DOM)
│   │   ├── types.ts       # public types: Payload, ProvisionalByte, DecoderEvent, Result
│   │   ├── bits.ts        # bytes <-> bits, Gray code
│   │   ├── crc32.ts
│   │   ├── reedSolomon.ts # GF(256) RS encode/decode
│   │   ├── interleave.ts  # pad/split, block interleave, whole-stream permutation
│   │   ├── tape.ts        # tape/ghost format: validate, serialize, deserialize
│   │   ├── frame.ts       # header, blocks, payload assembly
│   │   ├── accumulator.ts # multi-pass energy combining, keyed by tapeId
│   │   ├── equalize.ts    # per-tone gain estimates and correction (decoder option, off by default)
│   │   ├── profiles.ts    # tone tables and timing per profile
│   │   ├── modulate.ts    # symbols -> samples (MFSK, chirps)
│   │   ├── demodulate.ts  # samples -> symbols (Goertzel, timing)
│   │   ├── sync.ts        # preamble detection (matched filter), fine timing
│   │   ├── fft.ts         # radix-2 FFT shared by sync.ts and the channel simulator
│   │   ├── buffer.ts      # SampleBuffer: growing store addressed by absolute stream index
│   │   ├── decoder.ts     # streaming state machine: createDecoder, decodeFile
│   │   ├── channel.ts     # test-only channel simulator
│   │   └── index.ts       # encodePayload / createDecoder / decodeFile
│   ├── audio/             # browser adapters
│   │   ├── wav.ts         # pure WAV encode/decode
│   │   ├── file.ts        # upload decoding via decodeAudioData, mono mixing
│   │   ├── mic.ts         # getUserMedia (processing off) -> worklet -> worker
│   │   ├── capture.worklet.ts # AudioWorklet: 128-sample frames + audio clock to the worker
│   │   ├── decoder.worker.ts  # Web Worker owning the decoder; fills clock gaps with silence
│   │   ├── protocol.ts    # message types between UI, worklet and worker
│   │   ├── playback.ts    # play once / loop, WAV download
│   │   ├── modemWorker.ts # worker that also handles `encode` messages (same file as decoder.worker.ts if task 15 made one)
│   │   ├── workerClient.ts # typed client: listen, openFeed, encode, with timeout and terminate
│   │   ├── passScheduler.ts # schedules single passes on the audio clock for Side B
│   │   ├── wakeLock.ts    # navigator.wakeLock.request('screen'), re-acquired on visibilitychange
│   │   └── audioPortImpl.ts # implements the UI's AudioPort over the files above
│   └── ui/                # recorder, receiver, manifestation animation; dev.ts harness
│       ├── app.ts         # boot: shell, router, service worker registration, reduced-motion store
│       ├── router.ts      # matchRoute (pure, total), History API wiring, unmount hooks
│       ├── routes.ts      # route table: path, heading key, loader
│       ├── shell.ts       # navigation, main landmark, one h1, offline-ready chip, update notice
│       ├── announcer.ts   # polite live-region queue
│       ├── tokens.css     # design tokens (same names and values as tokens.ts)
│       ├── tokens.ts
│       ├── copy.ts        # every user-visible string (drafts until final copy)
│       ├── audioPort.ts   # the only way views reach audio: types plus DOM implementation
│       ├── carriers.ts    # Carrier profile table
│       ├── fragment.ts    # tape link fragment
│       ├── receiveUrl.ts  # receiveUrl(origin)
│       ├── qr.ts          # QR encoder, versions 1 to 6, level M
│       ├── qrView.ts      # canvas painter for the QR
│       ├── passClock.ts   # pass index from the audio clock (Side B)
│       ├── fileName.ts    # WAV and PNG file names
│       ├── spectrogram.ts # dev-only spectrogram (with dev.ts)
│       ├── darkroom/      # state, reduce, history, glyphs, layoutHint, sheet, timeline, viewModel (pure); glyphCanvas, darkroomView, controller (DOM)
│       ├── pages/         # home, receive, player, compose, broadcast
│       ├── jcard/         # jcardLayout (pure), jcardView (DOM)
│       ├── composer/      # draft, convert, validate, messages, duration, cassette, throttle, broadcastSuggest (pure); draftStore, composerView (DOM)
│       ├── print/         # layout (pure), render and share (DOM): save-as-image
│       ├── assets/        # ghost-tape-demo.wav generated by scripts/make-ui-demo.mjs (gitignored: src/ui/assets/*.wav)
│       └── fonts/         # subset EB Garamond woff2 (Regular, Italic), OFL.txt, README.md with the subsetting command
├── scripts/
│   ├── check-scramble.mjs # design-time check of the permutation rule (R8.11–8.16)
│   ├── make-demo-wav.mjs  # writes demo/ghost-tape-demo.wav (gitignored) to listen to
│   ├── measure.mjs        # npm run measure: single-pass success and symbol errors vs SNR, decoder speed
│   ├── measure-passes.mjs # npm run measure:passes: R6.3/R6.4 success vs passes, writes docs/passes-results.*
│   ├── measure-reverb.mjs # npm run measure:reverb: decode outcome vs RT60, header failure analysis (task 14)
│   ├── measure-alignment.mjs # npm run measure:alignment: alignment-rule false accepts and their harm (task 14)
│   ├── browser-smoke.mjs  # npm run smoke:browser: headless Chrome runs the dev harness on a WAV "microphone"
│   ├── measure-fixtures.mjs # npm run measure:fixtures: decode real-room recordings with and without equalization
│   ├── make-ui-demo.mjs   # npm run demo:ui: writes src/ui/assets/ghost-tape-demo.wav from the copy.ts demo text
│   ├── check-dist.mjs     # npm run check:dist: fails the build on missing worker, worklet, demo audio, _headers or precache entries
│   ├── check-bundle.mjs   # npm run check:bundle: first-load JS budget and QR size
│   ├── sw-template.js     # service worker template with __PRECACHE__ and __VERSION__
│   └── vite-sw-plugin.mjs # Vite plugin that writes dist/sw.js after the bundle is written
├── docs/                  # measured results and charts for the write-up (committed)
├── demo/                  # generated audio, not committed
├── tests/
│   ├── fixtures/real-room/ # real-room recordings (WAV) + manifest.json, task 16
│   ├── unit/
│   │   └── ui/            # UI unit and jsdom tests
│   ├── properties/        # fast-check property tests
│   │   └── ui/            # UI property tests (fcUi)
│   └── support/           # shared test harness: uiRuns.ts (fcUi: fixed seed, at least 100 runs), replay.ts (recorded and synthesized decoder feeds), runs.ts (seeded fast-check params), budget.ts (deep-suite audio cap), dsp.ts (FFT/Goertzel for measuring audio), profiles.ts (test-only 3-bit profile), arbitraries.ts (tape/ghost generators), tapes.ts (seeded tapes of an exact size), random.ts (seeded noise, re-exported from channel.ts), decode.ts (encode/decode/chunk helpers that count audio against the cap)
├── public/                # manifest.webmanifest, _headers, icons/ (icon-180/192/512 png, icon-maskable-512.png, ghost-tape.svg)
├── KIRO_LOG.md            # running log of how Kiro was used (for the write-up)
├── LICENSE                # MIT
└── README.md
```

- Tests mirror source names: `src/modem/frame.ts` -> `tests/properties/frame.prop.test.ts`.
- UI tests live in a `ui/` subfolder: `src/ui/router.ts` -> `tests/properties/ui/router.prop.test.ts` and `tests/unit/ui/`.
- New modem modules must be added to this tree.
- New UI and audio modules must be added to this tree.
- `.gitignore` also lists `src/ui/assets/*.wav`.
